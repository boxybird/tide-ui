Burque brings local evenings into one place: small shows, creative workshops, comedy and community gatherings. Start with what sounds interesting. Then use the event page to work out whether it is right for you.

Finding an event

Browse upcoming events and open a listing to read its date, venue, admission and practical details. Use the month links to move through the lineup.

Moving between events

On a wider screen, the list sits beside the event you are reading. In view identifies that preview. On a phone, opening an event gives its details the full screen. The back link returns you to browsing.

Before you go

An event page brings together the date, local start time, venue, admission and practical details supplied by its organizer. Check these before travelling. A listing is an invitation to find out more, not a booking confirmation.

Local times
Event times refer to Albuquerque. Check the date as well as the time, especially for a late-night event.
Age requirements
Look for the organizer’s stated age requirement. Ask if the listing does not make it clear.
Accessibility
Only confirmed access information should be treated as confirmed. If a detail is missing, ask the organizer about your specific needs.

A useful question can be specific:

Is there a step-free route from the entrance to the event space, and is seating available throughout the evening?

Understanding admission

These labels describe admission; they do not reserve a place. Check the organizer’s current instructions for fees, capacity and any registration deadline.

Common admission labels
LabelWhat it tells youWhat to check
FreeNo admission charge is listed.Whether registration or a reservation is still needed.
A listed priceThe organizer has supplied an admission price.Fees, concessions and where to buy a ticket.
RSVP requiredThe organizer asks you to register.The deadline and whether your place has been confirmed.

When plans change

Dates, venues and availability can change. Before setting out, check the event page and the organizer’s latest information.

  • Cancelled: the event is no longer going ahead. Ask the ticket seller about any refund.
  • Time changed: read the updated time and date, rather than relying on an earlier message or screenshot.
  • Sold out: check directly with the organizer for an official waiting list or another date.

If two sources disagree, confirm with the organizer before making plans. Include the event name and date when asking about an incorrect listing.

Sharing an event

Copy the individual event’s address from your browser. That gives someone a direct route to its details.

Listing something of your own

The Add an event form shows the information a useful listing needs. Prepare:

  • A clear event name and a short description of what people will do.
  • The date, start time, venue and address.
  • Admission, age requirements and confirmed accessibility information.
  • An organizer contact and, optionally, a photo you have permission to share.

A straightforward phone photo is enough. Important details should also be written as text, so visitors can find them without having to read a poster image.

Still need help?

The organizer is the best source for access arrangements, tickets and last-minute changes. Include the event name and date when asking a question.

You can return to all events or check the venue’s website for visitor information.
