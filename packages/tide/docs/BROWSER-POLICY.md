# No browser JavaScript in Tide

Tide supplies semantic HTML, CSS, themes and assets. Neither canonical HTML nor the distributed package may contain script imports, executable script files, inline event handlers or JavaScript URLs. The repository checks enforce this boundary before packaging.

Use native links, controls, reset, disclosure and browser constraint validation. Style actual native states with CSS. Author example states where a service or behavior engine would otherwise be needed. An error summary may be rendered as a static example; do not claim that CSS computes validation results or announces changing errors. File inputs use the native chooser and accept hints; no custom size/content validation is implied.

The two previous canonical recipe specimens referenced a documentation-only demo script. Tide 1.5.1 removes those references. The reference site is now script-free too. Python/Node remain repository development tools only.
