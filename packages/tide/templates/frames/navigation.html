Website navigation recipe

Every page has a place.

Native links, a clear current page and room for longer labels.

Navigation at narrow widths

The links wrap into additional rows, keeping every destination available without a menu script. The header stays in document flow. Its height can grow with larger text.

Current page

The current link uses aria-current="page", stronger text and a thicker underline. Focus remains a separate visible state. A detail page does not pretend to be the venue directory.

Native behavior

Tab through the links, use Enter, open a link in another tab or follow the skip link to the main landmark. There are no menu roles or arrow-key expectations.
