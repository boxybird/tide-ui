# Burque events example · 1.1.5

A framework-free consuming app for Tide 1.3.0. It includes 54 authored sample events, the accepted sticky month-heading hierarchy, live draft search counts, pinned Show events actions and the Sunshine Theater venue journey. Its deliverables are reusable UI patterns and example pages, evaluated with local sample data and interactions. See [project scope](../../README.md#project-scope); operating an events service is outside that scope.

Build and preview from the repository root: `npm run build`, `npm run check`, `npm run dev`. Open `/events/app/index.html?preview-filters=open`. `/events/index.html` links to complete examples for all six theme/mode combinations. All pages consume the one `build/tide/css/tide.css` distribution.

Edit `src/templates/` for shared app markup, including `document.html`, `workspace.html` and `event-detail.html`. `data/events.json` is the canonical 54-event fixture for cards and individual details; `data/detail-presentations.json` preserves the two existing detail compositions. `data/pages.json` records the six non-event route contexts. Only the three unique venue/help/submission fragments remain in `src/pages/`; route metadata selects their layout and source. Eleven standard submission fields share recipes and `data/submission-fields.json`. Event URLs are generated directly from sample IDs. See [template authoring](docs/TEMPLATES.md), [detail content](docs/DETAILS.md) and [venue/utility composition](docs/PAGES.md).

The build expands registered partials before resolving `{{KIT_CSS}}`, `{{APP_CSS}}` and `{{KIT_ASSETS}}` paths. The five stylesheet modules in `src/styles/` bundle in manifest order; browser behavior remains in `src/runtime/`, with registered shared services, navigation, filters/rail and isolated preview hooks. See [runtime ownership](docs/RUNTIME.md). Search tests use the same canonical card data, without needing generated output. All data remains authored samples, not a live ingestion pipeline.

App-only styles now have purpose-based homes: base, lineup, desktop geometry, responsive filters and venue composition. Study-era aliases and inactive variants are removed. The kit's CSS, HTML recipes, tokens and assets are unchanged. Keep the bounded list, natural right document, unframed panes, semantic tokens, native scrollbar allowance and responsive filter behavior. See [component ownership](docs/COMPONENT-OWNERSHIP.md), [sample data](docs/SAMPLE-DATA.md) and [page refactor verification](../../docs/refactors/utility-pages/VERIFICATION.md).
